# Organizador de Declaração de Imposto de Renda Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da [Digital Innovation One (DIO)](https://www.dio.me/). O objetivo é criar uma ferramenta no Excel para reunir e organizar informações importantes para a preparação da declaração do Imposto de Renda.

A planilha funciona como um agregador de dados, facilitando o registro e a consulta de informações pessoais, informes de rendimentos e entradas financeiras em um único arquivo.

## Objetivos

* Organizar informações necessárias para a preparação da declaração do Imposto de Renda.
* Facilitar o registro e a consulta de rendimentos e movimentações financeiras.
* Aplicar recursos do Excel na construção de uma ferramenta prática.
* Desenvolver habilidades de organização de dados e documentação técnica.
* Compartilhar o projeto utilizando o GitHub.

## Estrutura da planilha

### 1\. Titular

Aba destinada ao cadastro dos dados pessoais do contribuinte, como nome, CPF, data de nascimento, endereço e informações de contato.

### 2\. Informes

Aba destinada à organização de informes de rendimentos bancários e dos valores correspondentes, permitindo centralizar informações relevantes para a declaração.

### 3\. Notas

Aba destinada ao registro de entradas financeiras, com campos para data, categoria e valor, auxiliando no acompanhamento das movimentações.



## &#x20;Como utilizar

1. Baixe o arquivo `Organizador de Declaração de Imposto de Renda.xlsx` deste repositório.
2. Abra a planilha no Microsoft Excel ou em uma ferramenta compatível.
3. Preencha a aba **Titular** com os dados correspondentes.
4. Registre os informes de rendimentos na aba **Informes**.
5. Utilize a aba **Notas** para organizar as entradas financeiras.
6. Revise as informações e mantenha os documentos comprobatórios organizados.
